# DSクラフト ルール

3DS半分こするくらい仲良しクラフト（DSクラフト）のルール・ルール施行令・国内法の条文と、その改正履歴を管理するリポジトリです。

条文は [DSクラフト ルールポータル](https://www.ds2.uk/rule/) で公開しています。ポータルのソース（[ds-craft/portal](https://github.com/ds-craft/portal)）は、このリポジトリをサブモジュールとして `_rules/` に取り込んでいます。

## 構成

```
.
├── rules/            # 施行中のルール（1ファイル ＝ 1ルール）
│   └── repealed/     # 廃止したルール（廃止した時点の最終版）
├── README.md
└── LICENSE           # CC BY-SA 4.0
```

ファイル名は `R` ＋ 令和の年（2桁）＋ 種別（`01` ルール / `02` ルール施行令 / `10` 国内法）＋ 号（3桁）です。

例：令和7年ルール第1号 → `rules/R0701001.md`

各ファイルは、ポータルでそのままページになる Markdown（front matter 付き）です。書式はポータルの README の「ルールの追加・改正・廃止」を参照してください。

## 改正履歴の読み方

1回の改正行為（ルールの制定・一部改正・廃止）を、1つのコミットとして記録しています。

| 項目 | 内容 |
|---|---|
| 日時 | 施行日の 00:00（日本時間） |
| 作者 | 改正を行ったルールの番号（例：`令和8年ルール第1号`） |
| 件名 | `〈ルール名〉 施行`、一部改正は `〈対象〉の一部を改正するルール 施行` |
| トレーラー | `Rule-Id`（変更したルール）、`Enforced`（施行日）、`Repeals`（廃止したルール） |

コミットの日時は施行日を表すもので、このリポジトリでの公開日ではありません（このリポジトリの公開は2026年11月9日）。

あるルールの附則が他のルールを改正・廃止する場合は、そのルールのコミットにまとめています。ルールを別番号のルールで置き換えた場合は、旧ファイルを `rules/repealed/` に移し、front matter に `repealed_date`（廃止日）と `repealed_by`（廃止したルールの番号）を足します。

```bash
# 改正の一覧
git log --format="%ad  %an  %s" --date=short

# あるルールの改正履歴（廃止したルールも --follow で移動前から追える）
git log --follow -p -- rules/R0701001.md

# ある日に施行されていた条文
git show $(git rev-list -1 --before="2025-01-01T00:00+09:00" main):rules/R0501001.md
```

### 2026年10月以前の記録について

運用開始より前の改正（令和4年〜令和8年8月）は、当時の文書から復元して記録しています。

- 令和4年9月25日の版は、正本の画像をもとにしています。
- 番号のなかった改正にも、記録のためにルール番号を付けています（令和4年ルール第4号・第5号、令和6年ルール第1号、令和7年ルール施行令第2号・第3号、ディープステート基本法は令和4年国内法第1号）。
- 見出し・条番号・項・号の書式は現行の形式に揃えています。本文の文言は、明らかな誤記を除いて原文のままです。
- 個人のアカウント名・プレイヤー名は〔個人名省略〕のように伏せています（〔〕内は記録にあたっての注記です）。
- 2023〜2025年の国名の変更は記録が残っていないため、令和7年6月19日にまとめて変わった扱いにしています。
